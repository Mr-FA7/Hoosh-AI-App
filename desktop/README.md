# Hoosh Desktop Browser
#
# Local-first shell: PyQt6 WebEngine + Hoosh Runtime (companion.js).
# The website (aihoosh.com) is marketing + download only.
#
# Quick start (dev):
#   pip install -r desktop/requirements.txt
#   npm run build
#   python desktop/main.py
#
# Package:
#   python scripts/protect_hoosh_desktop.py   # optional PyArmor
#   npm run desktop:build:mac                # PyInstaller + DMG
