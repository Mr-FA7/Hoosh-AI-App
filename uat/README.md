# Universal AI Terminal (UAT) — داخل Fard

این پوشه همان **موتور UAT** است (CLI، لایهٔ دستور، ایمنی، …) و بخشی از **Fard Terminal** محسوب می‌شود.

- اجرای CLI از ریشهٔ پروژهٔ Fard: `npm run uat -- doctor`
- معماری: `docs/ARCHITECTURE.md`
- تست‌ها: `npm run test:uat`

از رابط گرافیکی از طریق `window.fard.uat` در preload در دسترس است.
